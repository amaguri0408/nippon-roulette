# 郵便番号ランダム抽選プロジェクト 仕様書

## 1. 概要

日本全国の**実在郵便番号**からランダム抽選し、地図上で候補が絞られていく演出を提供する。

## 2. 体験要件（UX）

- 最後まで行き先が読めない演出
- 抽選は**下位桁から**確定（1桁→7桁）
- 抽選途中で候補数表示（例: 残り1324件）
- 地図上で不一致候補を段階的に除去
- 最終的に1地点を強調表示

## 3. データ要件

### 3.1 入力データ

1. `utf_ken_all.csv`（日本郵便）
   - ヘッダーなし（`header=None`）
   - 郵便番号・都道府県・市区町村・町域・読み仮名
2. `latest.csv`（住所→緯度経度）
   - 都道府県・市区町村・町丁目・緯度・経度

### 3.2 出力データ

- `data/zip_geo.json`
  - 1郵便番号につき代表1点
  - 主要項目: `zip7`, `pref`, `city`, `town`, `lat`, `lon`, `score`, `match_type`

## 4. マッチング要件

### 4.1 必須条件

- `pref` 完全一致
- `city` 完全一致

### 4.2 town 比較優先順位

1. 漢字完全一致
2. 漢字前方一致
3. カナ完全一致
4. カナ部分一致
5. 不一致

### 4.3 正規化

少なくとも以下を実施:

- 全角数字→半角
- 全角/半角空白除去
- `ヶ/ケ` など表記ゆれ吸収
- 括弧情報除去
- `丁目/番地` など詳細ノイズの軽減

### 4.4 特殊ケース

- `town = 以下に掲載がない場合` は通常町域として扱わない
- 郵便番号末尾 `00` の代表系は別扱い（除外または低優先）

## 5. 性能要件

- 全件直積mergeは禁止
- `pref+city` キーでグルーピングし、グループ内探索
- メモリ効率重視（辞書化・逐次処理）

## 6. フロント要件

- Vanilla JS + Leaflet
- OpenStreetMapタイル利用
- 抽選進行に応じた候補フィルタ
- 最終結果カード表示
